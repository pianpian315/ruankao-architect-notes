## 七、答题策略速览

### 上午选择题
- 2 分钟 / 题，不会的先标记跳过
- 5 道英语题，对 3 题即可
- 数学难题可放弃，把基础题保住
- **目标 50+ 分**（容错 25 道）

### 下午Ⅰ 案例题
- **题 1 必答**（架构评估），稳拿 15+ 分
- 推荐选答：**题 4（设计模式/UML）+ 题 3（数据库）** —— 客观性强
- 谨慎选答：题 5（嵌入式，专业性强）
- 关键词靠前 + 分点作答 + 量化指标 + 按机制/条件/结果三段式

### 下午Ⅱ 论文题
- 4 选 1，优先选**微服务 / 架构评估 / 高可用 / 数据架构**（4 大 P0 模板覆盖近 2 年 70%+ 真题）
- 摘要必写 300+ 字（决定第一印象）
- 正文必到 **2500 字以上**（字数不够直接低分）
- 论点 4-6 个 + 每个论点配 1 个量化指标 + 适当反思
- **必备**：背熟"项目背景库"3 套（电商 + 金融 + 政务）→ 见《论文速记》§16
